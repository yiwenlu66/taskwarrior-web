# Deployment memory

Machine-specific deployment facts and operations belong in `../local/deployment.md` (when present): host/URLs, installed systemd user unit, Tailscale binding and trusted aliases, Taskwarrior paths, update/restart procedures, and non-mutating health checks. That file is intentionally git-ignored; consult it before changing the local service.

Generic deployment source of truth: `README.md`, `BACKEND.md`, `scripts/install-service.sh`, and `deploy/taskwarrior-web.service.example`. The installed unit is generated by the installer. Frontend builds update `dist/`; backend changes require a service restart. A new hostname requires trusted-alias registration even if GET requests already work.

Keep private task data, machine-specific paths/addresses, production screenshots, and local operational notes out of this public repository. Test mutations only against isolated TASKRC/TASKDATA fixtures.
